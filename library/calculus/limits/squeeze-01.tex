Use the squeeze theorem to evaluate $\displaystyle\lim_{x\to 0} x^2\cos(1/x)$.
\begin{solution}
  $-x^2 \le x^2\cos(1/x) \le x^2$ and both bounds tend to $0$, so the limit is $0$.
\end{solution}
\end{problem}
